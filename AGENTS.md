# Agent Guidelines - acr-logos

## Brand Identity & Vector Asset Discipline
1. **Vector-First Standard**: Maintain source vector assets in `svg/` and `illustrator/` alongside high-res raster exports in `png/` (including `1024x1024` plugin icon).
2. **Color Palette Invariant**: Adhere strictly to the canonical `@acr-js/branding` themes — Production Zyphra Orange (`#FF8C42` -> `#FF5500` -> `#E04800` on `#000000` / `#0D0D11`) and Protocol Gradient (`#38bdf8` -> `#6366f1` -> `#34d399`).
